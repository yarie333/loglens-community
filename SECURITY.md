# Security Policy

## Supported Versions

LogLens Community is an open-source project. Security fixes are prioritized for the latest stable release.

| Version | Supported |
|---|---|
| 1.0.x | Yes, following the v1.0.0 release |
| Earlier development versions | No |

## Reporting a Vulnerability

If you discover a potential security vulnerability in LogLens Community, please report it privately.

You can report vulnerabilities through GitHub's private vulnerability reporting feature, if enabled for this repository.

**Repository:** https://github.com/yarie333/loglens-community

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected component or feature.
- The potential security impact.
- Suggested fixes, if available.

Do not publicly disclose vulnerabilities before they have been reviewed.

## Privacy and Data Protection

LogLens Community is designed to analyze Windows event logs locally.

Users should avoid uploading sensitive or confidential logs to public websites or sharing them in GitHub Issues.

Before sharing diagnostic information, remove personal information, credentials, IP addresses, usernames, and other sensitive data.

## Security Best Practices

- Download LogLens Community from the official GitHub repository.
- Keep Python, Docker Desktop, and dependencies updated.
- Review detection findings before taking action.
- Do not treat every security finding as confirmation of malicious activity.
- Use the application only on systems and logs you are authorized to analyze.

## Response Process

Reported vulnerabilities will be reviewed and prioritized according to their potential impact and reproducibility. Fixes will be developed and tested before public disclosure when appropriate.

As a community-maintained project, specific response or resolution times are not guaranteed.
